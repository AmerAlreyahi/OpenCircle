# Save and copy

Copy a selection as an image, or save it straight to your chosen folder.

## How to

1. Choose a save folder in **Settings › General** if you want a particular location.
2. Press `Ctrl+Shift+Space` and circle or drag a box around what you want to keep.
3. Press `Ctrl+C` to copy the image, then paste it into another app.
4. Or press `Ctrl+S` to save straight to the save folder, without a file dialog.
5. Look for the confirmation pill: **Copied** or **Saved to …**.

## Shortcuts

| Shortcut | What it does |
|---|---|
| `Ctrl+Shift+Space` | Open the overlay |
| `Ctrl+C` | Copy the box as an image only |
| `Ctrl+S` | Save the selected image |
| `Esc` | Close the overlay; leave the question field first if focused |

## Tips

- Image copy puts only the picture on the clipboard. It does not add recognised text.
- To copy words instead, select the text or choose **Copy text**. See [Select text](select-text.md).
- Without a chosen folder, saves go to **OpenCircle** inside your Pictures folder.
- Saves get a date and time in their name. If a name is already taken, OpenCircle adds a number. It never overwrites an existing file.

## Limits

- `Ctrl+C` copies text when you have selected words. Draw an image box to copy a picture.
- Saving needs a writable folder. If it fails, the pill asks you to pick another folder in Settings.
- The confirmation pill is brief. Check the save folder if you missed it.
