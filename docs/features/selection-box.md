# Adjust the selection box

Move and resize the box until it contains exactly what you want.

## How to

1. Press `Ctrl+Shift+Space`, then circle or drag around an area.
2. Drag an edge or corner to resize the box.
3. Drag inside the box to move it. Hold `Alt` while dragging inside if there is text under the pointer.
4. Use the arrow keys for small moves. Hold `Shift` for 10-pixel steps, or `Ctrl` to resize instead.
5. Press `Ctrl+C` to copy the selected image.

## Shortcuts

| Shortcut | What it does |
|---|---|
| Arrow keys | Move the box by 1 pixel on screen |
| `Shift` + arrow keys | Move by 10 pixels |
| `Ctrl` + arrow keys | Resize the box by 1 pixel |
| `Ctrl+Shift` + arrow keys | Resize by 10 pixels |
| `Alt+drag` inside | Move the box even over text |
| `Ctrl+C` | Copy the box as an image |
| `Esc` | Close the overlay; leave the question field first if focused |

## Tips

- Use the corners for a quick rough fit, then the keys for a small adjustment.
- **Copy text** in the bar reads the words inside the box. `Ctrl+C` copies the picture of the box.
- See [Save and copy](save-and-copy.md) to keep the image in a folder.

## Limits

- The box stays within the captured screen and has a minimum size.
- Arrow adjustments apply to an image selection. Selected words use text-selection behaviour instead.
- Dragging over text can select words; hold `Alt` to move the existing box.
